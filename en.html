S–01 / TYPEWRITER

write quietly.AI, when invited.

Typewriter is a Windows-first, local-first Markdown writing app. Documents stay on the machine by default; workspaces, search, archives, autosave, version snapshots and conflict handling keep it useful without AI. When help is wanted, the writer can explicitly enable restrained suggestions, proofreading and rewriting.

LOCAL FIRSTMARKDOWNCONTROLLED AITAURI / WINDOWS
01 / Local work

Writing works offline

On-device documents, workspaces, Markdown and text import/export, search, archives, autosave, version snapshots and disk-conflict handling.

02 / Controlled AI

Preview before applying

Subtle ghost-text continuation plus proofreading, continuation, rewriting, tightening, naturalizing, expansion, ideas and summaries — always under the writer's control.

03 / Long-form support

Check facts, don't seize the pen

Quietly tracks characters, time, numbers and causality, preserving fact cards and conflict warnings. Style is learned only from text the writer explicitly selects.

04 / Privacy design

AI starts off

AI requires explicit consent and sends only the excerpt needed for the task. In the personal build, the Tauri Rust process reads the API key from a local environment variable.
