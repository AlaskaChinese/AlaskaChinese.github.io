S–01 / TYPEWRITER

安静地写。需要时，AI 出现。

Typewriter 是一款 Windows 优先、本地优先的 Markdown 写作应用。文档默认保存在本机；工作区、搜索、归档、自动保存、版本快照和冲突处理让它在没有 AI 时也能完整工作。需要帮助时，再明确开启克制的续写、校对与改写。

LOCAL FIRSTMARKDOWN可控 AITAURI / WINDOWS
01 / 本地工作

离线也能写

本机保存、工作区、Markdown / 文本导入导出、搜索、归档、自动保存、版本快照与磁盘冲突处理。

02 / 可控 AI

先预览，再应用

灰字续写，以及校对、续写、改写、简洁化、自然化、扩写、想法与总结；正文变化始终由用户确认。

03 / 长文辅助

检查事实，不抢笔

静默整理人物、时间、数字与因果设定，保留事实卡与冲突提示；文风只学习明确勾选的本机文字。

04 / 隐私设计

默认不调用 AI

AI 需明确开启，只发送当前任务所需片段；个人开发版的 API Key 由 Tauri Rust 进程从本机环境变量读取。
